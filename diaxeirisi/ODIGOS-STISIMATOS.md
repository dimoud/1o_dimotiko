# Στήσιμο του Πίνακα διαχείρισης (μία φορά, ~40 λεπτά)

Αρχιτεκτονική: **ένας** λογαριασμός Google του σχολείου κατέχει Φύλλο, Drive και σενάριο.
Οι εκπαιδευτικοί **δεν** μπαίνουν στον λογαριασμό· ανοίγουν έναν σύνδεσμο (τον Πίνακα) και γράφουν
τον κωδικό του ρόλου τους. Ο κωδικός Συντάκτη στέλνει για έγκριση· ο κωδικός Διεύθυνσης εγκρίνει και δημοσιεύει.

## Α. Λογαριασμός Google του σχολείου
1. Νέος λογαριασμός Gmail, π.χ. `istoselida.1dimpolichnis@gmail.com`, με ισχυρό κωδικό.
2. Επαλήθευση σε δύο βήματα με **email ανάκτησης** το `mail@1dim-polichn.thess.sch.gr` και κωδικούς
   ανάκτησης τυπωμένους στον φάκελο της Διεύθυνσης (όχι προσωπικό κινητό).
3. Τον κωδικό του λογαριασμού τον ξέρει μόνο η Διεύθυνση και ο τεχνικός υπεύθυνος.

## Β. Φύλλο και σενάριο
4. Στον λογαριασμό αυτό: Google Drive → Νέο → Υπολογιστικό φύλλο, όνομα «Ιστοσελίδα σχολείου – Διαχείριση».
5. Επεκτάσεις → Apps Script. Μετονομασία έργου: «Πίνακας ιστοσελίδας».
6. Στο `Code.gs` σβήστε ό,τι υπάρχει και επικολλήστε το `diaxeirisi/Code.gs`.
7. Αρχεία → + → HTML, όνομα `Index` → επικολλήστε το `diaxeirisi/Index.html`.
8. Ρυθμίσεις έργου (γρανάζι) → τσεκάρετε «Εμφάνιση αρχείου μανιφέστου appsscript.json» → στο `appsscript.json`
   επικολλήστε το `diaxeirisi/appsscript.json`. Αποθήκευση.
9. Επιστροφή στο Φύλλο, ανανέωση σελίδας → εμφανίζεται το μενού **Ιστοσελίδα**.
10. Ιστοσελίδα → **1. Αρχικοποίηση** → εγκρίνετε τα δικαιώματα (Advanced → Go to… → Allow).
    Φτιάχνει καρτέλες, φάκελο «Ιστοσελίδα σχολείου – Αρχεία» και εβδομαδιαίο αντίγραφο.
11. Ιστοσελίδα → **2. Ορισμός κωδικών** (Συντάκτη ≥ 8 χαρακτήρες, Διεύθυνσης ≥ 10, διαφορετικοί).

## Γ. Σύνδεση με το GitHub
12. github.com (λογαριασμός dimoud) → Settings → Developer settings → Personal access tokens →
    **Fine-grained tokens** → Generate: Repository access *Only select* → `1o_dimotiko`·
    Permissions → Repository → **Actions: Read and write** (τίποτα άλλο)· λήξη 1 έτος. Αντιγραφή.
13. Φύλλο → Ιστοσελίδα → **3. Κλειδί GitHub** → επικόλληση.
14. Apps Script → Ανάπτυξη → Νέα ανάπτυξη → τύπος **Εφαρμογή ιστού**: Εκτέλεση ως **Εγώ**, Πρόσβαση **Οποιοσδήποτε**
    → Ανάπτυξη. Κρατήστε τη διεύθυνση `https://script.google.com/macros/s/…/exec` = **ο Πίνακας**.
15. Φύλλο → Ιστοσελίδα → **Εμφάνιση κλειδιού API** → αντιγραφή.
16. GitHub → αποθετήριο `1o_dimotiko` → Settings → Secrets and variables → Actions → New repository secret:
    - `DEDOMENA_URL` = η διεύθυνση `/exec` του βήματος 14
    - `DEDOMENA_KLEIDI` = το κλειδί API του βήματος 15
    > Μέχρι να γίνει η εισαγωγή (Δ), ο ιστότοπος συνεχίζει από τα αρχεία του αποθετηρίου: αν το Φύλλο είναι άδειο,
    > η δημοσίευση αγνοεί το Φύλλο. Δεν αδειάζει ποτέ.

## Δ. Μεταφορά του σημερινού περιεχομένου
17. Στον υπολογιστή, από τον φάκελο `istotopos`: `python ergaleia/paketo_eisagogis.py` → φτιάχνει `_eisagogi/Εισαγωγή/`.
18. Στο Drive του σχολείου, μέσα στο «Ιστοσελίδα σχολείου – Αρχεία / Εισαγωγή», σύρετε **τα περιεχόμενα**
    του `_eisagogi/Εισαγωγή/` (το `eisagogi.json` και τους φακέλους `fotografies`, `arxeia`). Περιμένετε να ανέβουν όλα.
19. Φύλλο → Ιστοσελίδα → **4. Εισαγωγή**. Αν πει «συνεχίζεται», ξανά το ίδιο μέχρι «ολοκληρώθηκε».
20. Στον Πίνακα (Διεύθυνση) ανοίξτε μια ανάρτηση → «Δημοσίευση». Στο GitHub → Actions πρέπει να τρέξει
    «Δημοσίευση ιστότοπου» με βήμα «Περιεχόμενο από τον Πίνακα διαχείρισης» (πρώτη φορά ~10 λεπτά: κατεβαίνουν οι φωτογραφίες).

## Ε. Παράδοση στους ανθρώπους
21. Ο σύνδεσμος του Πίνακα μπαίνει ως σελιδοδείκτης στους υπολογιστές του σχολείου.
22. Κωδικός Συντάκτη → στους εκπαιδευτικούς που γράφουν. Κωδικός Διεύθυνσης → μόνο στη Διευθύντρια.
23. Ειδοποιήσεις: Ρυθμίσεις → email (π.χ. `mail@1dim-polichn.thess.sch.gr`).

## Όταν αλλάζουν τα πρόσωπα (π.χ. τέλος σχολικής χρονιάς)
- Νέα Διεύθυνση: Πίνακας → Ρυθμίσεις → νέος κωδικός Διεύθυνσης και Συντάκτη (όλοι αποσυνδέονται).
- Αλλαγή κωδικού του λογαριασμού Google του σχολείου και του email ανάκτησης αν χρειάζεται.
- Τίποτα δεν είναι δεμένο σε προσωπικό κινητό ή προσωπικό λογαριασμό.
- Κάθε χρόνο: νέο κλειδί GitHub (βήματα 12–13)· ο Πίνακας το θυμίζει από τη μέρα 330.

## Αλλαγή κώδικα σεναρίου
Μετά από κάθε επικόλληση νέου `Code.gs`/`Index.html`: Ανάπτυξη → Διαχείριση αναπτύξεων → μολύβι → Έκδοση: **Νέα** → Ανάπτυξη.
Η διεύθυνση `/exec` μένει ίδια.
