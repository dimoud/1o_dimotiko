# Ιστότοπος 1ου Δημοτικού Σχολείου Πολίχνης

Στατικός ιστότοπος (μόνο HTML/CSS/λίγο JS), παράγεται από δεδομένα JSON με Python και δημοσιεύεται στο GitHub Pages.
Πλάνο: `PLANO.md` · Σχεδιαστική κατεύθυνση: `KATEYTHYNSI.md`

## Δομή

```
istotopos/                       ← αυτός ο φάκελος είναι το αποθετήριο GitHub
├── build/                       γεννήτρια: build.py (σελίδες) · kelyfos.py (κεφαλίδα/μενού/υποσέλιδο, ΜΙΑ πηγή) · md.py (κείμενα)
├── static/                      site.css · site.js · site-search.js · favicon.svg · fonts/ (Commissioner, τοπικά)
├── periexomeno/                 ΤΟ ΠΕΡΙΕΧΟΜΕΝΟ
│   ├── anartiseis.json          αναρτήσεις (2024 και μετά)
│   ├── selides.json             σταθερές σελίδες (Το Σχολείο μας, Γονείς) · "katastasi": "Δημοσιευμένη" | "Πρόχειρο"
│   ├── selides-wp.json          κείμενα σελίδων από το παλιό WordPress (πηγή για το selides.json)
│   ├── diktya.json              δίκτυα και προγράμματα (λογότυπα: πεδίο "logotypo")
│   ├── syndesmoi.json           χρήσιμοι σύνδεσμοι
│   └── rythmiseis.json          όνομα, διεύθυνση, τηλέφωνο, email, κεντρική φωτογραφία, τομέας
├── meson/                       φωτογραφίες (WebP 800/1600, χωρίς EXIF) και αρχεία (PDF, MP4)
├── ergaleia/                    μεταφορά από το παλιό WordPress (wp_eksagogi.py, fotografies.py)
└── .github/workflows/           δημοσίευση στο GitHub Pages σε κάθε push
```

Οι σελίδες που παράγονται:

| Διεύθυνση | Τι |
|---|---|
| `/` | Αρχική |
| `/sxoleio/…` | Το Σχολείο μας: ιστορία, Διεύθυνση και προσωπικό, κανονισμός, βιβλιοθήκη, κήπος |
| `/zoi/…` | Σχολική Ζωή ανά ενότητα (ανακοινώσεις, δράσεις, γιορτές, περιβάλλον…) |
| `/anartiseis/<έτος>/<τίτλος>/` | Μία σελίδα ανά ανάρτηση, με φωτογραφίες που ανοίγουν σε μεγάλη προβολή |
| `/diktya/…` | Ένα δίκτυο/πρόγραμμα ανά σελίδα, με τις σχετικές αναρτήσεις |
| `/diagonismoi/` | Διαγωνισμοί και διακρίσεις ανά σχολικό έτος |
| `/goneis/…` | Γονείς και Κηδεμόνες |
| `/arxeio/<σχολικό έτος>/` | Αρχείο ανά σχολικό έτος |
| `/syndesmoi/` `/epikoinonia/` `/anazitisi/` | Σύνδεσμοι · Επικοινωνία και χάρτης · Αναζήτηση |
| `/prosvasimotita/` `/aporrito/` | Δήλωση προσβασιμότητας (ΚΥΑ 2418/Δ3/2026) · Απόρρητο |

Κανόνες που ελέγχει ο κώδικας: τίποτα πριν από 01/01/2024 · σελίδα «Πρόχειρο» δεν δημοσιεύεται και δεν μπαίνει στο μενού ·
ενότητα χωρίς αναρτήσεις δεν μπαίνει στο μενού · χάρτης και YouTube φορτώνουν μόνο με πάτημα · καμία κλήση σε Google Fonts/Analytics.

## Τοπικά

```
python3 build/build.py            # → _site/
cd _site && python3 -m http.server 8000   # → http://localhost:8000
```

## Δημοσίευση στο GitHub (πρώτη φορά)

1. Νέο αποθετήριο στο GitHub (π.χ. `1o_dimotiko`), δημόσιο.
2. Από αυτόν τον φάκελο: `git init -b main && git add . && git commit -m "Αρχική έκδοση" && git remote add origin <url> && git push -u origin main`
3. Στο αποθετήριο: Settings → Pages → Source: **GitHub Actions**. Η πρώτη δημοσίευση γίνεται αυτόματα (2–3 λεπτά).
4. Με δικό τομέα: Settings → Pages → Custom domain, `"tomeas"` και `"cname"` στο `periexomeno/rythmiseis.json`, εγγραφές DNS στον καταχωρητή.

Χωρίς δικό τομέα ο ιστότοπος δουλεύει σε υποφάκελο (`<λογαριασμός>.github.io/1o_dimotiko/`): το workflow περνά αυτόματα τη διαδρομή στη γεννήτρια.
